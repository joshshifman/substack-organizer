# substack-organizer

A Chrome extension for sorting Substack subscriptions into folders and pinning the ones you read most.

> **Unofficial and experimental.** This project is not affiliated with or endorsed by Substack. It relies on Substack's undocumented web API, which can change or stop working at any time. Review [Substack's Terms of Use](https://substack.com/tos) before using it.

Clicking the toolbar icon opens a reader tab:

- **Pinned** shows the latest posts from pinned publications.
- **Folders** each show their publications' latest posts. A publication can be in several folders. Drag a publication onto a folder to file it; drag folders to reorder them.
- **Unsorted** lists subscriptions that aren't in any folder yet.
- **All subscriptions** lists everything, with pin and folder controls.

## Install

```sh
pnpm install
pnpm build
```

Then open `chrome://extensions`, turn on **Developer mode**, click **Load unpacked**, and choose `dist/chrome-mv3`. Pin the extension and click its icon while signed in to Substack. Requires Chrome 116 or later.

## Your data

Nothing leaves your browser except requests to Substack.

- **Subscriptions and posts** are fetched from substack.com with your existing login and cached in `chrome.storage.local`. The extension never reads or stores your cookies.
- **Folders and pins** (folder names and publication IDs) are saved in `chrome.storage.sync`. If Chrome Sync is on, Google syncs them to your other Chrome installs. If you edit on two devices at once, the last change wins.
- **Export folders** in the sidebar downloads a JSON backup.

## How it gets data

The extension only has permission for `https://substack.com/*`:

| Endpoint | Used for |
| --- | --- |
| `GET /api/v1/user/profile/self` | Your subscriptions, each with its publication nested (needs login) |
| `GET /api/v1/subscriptions?tvOnly=false` | Fallback when the profile lists none; it can return an empty list on real accounts |
| `GET /api/v1/profile/posts?profile_user_id={author}` | Recent posts, filtered to the publication |

## Known limits

- Posts come from each publication author's profile feed. Publications whose listed author posts elsewhere show no posts, and guest posts by other writers are not shown.
- The merged "Latest posts" feed is only available for views of 60 publications or fewer.
- Chrome sync storage is small: a folder holds up to roughly 1,000 publications, and all folders and pins together must fit in about 100 KB.

## Develop

```sh
pnpm dev                 # Chromium with the extension and hot reload
pnpm test                # unit tests
pnpm typecheck
pnpm build && pnpm e2e   # drives the built extension in Chromium against fixture data
pnpm icons               # re-export public/icon/*.png after editing assets/icon.svg
```

`tests/fixtures` holds invented publications and posts generated by `node scripts/make-fixtures.mjs`; tests never contact Substack.
